# Task 2: Predictive Modeling Strategy

## Objective
Develop a conceptual approach for predicting customer delinquency using the Geldium case study.

## Proposed Approach
- Identify relevant input features based on the dataset and EDA findings.
- Compare suitable modeling options and justify the recommended approach.
- Outline the workflow from data preparation to risk prediction.
- Define evaluation metrics for predictive performance and fairness.

## Evaluation Considerations
- Accuracy and F1 score
- ROC-AUC
- Class imbalance and false-negative risks
- Fairness across relevant customer groups
- Model interpretability and transparency

## Deliverables
The original modeling plan and supporting submission document will be added where appropriate.

## Important Note
This task concerns a proposed modeling strategy. It should not be interpreted as a trained or deployed predictive model.
