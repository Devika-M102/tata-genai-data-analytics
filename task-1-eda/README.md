# Task 1: Exploratory Data Analysis (EDA)

## Objective
Assess the Geldium dataset's structure, completeness, and data quality before predictive modeling.

## Analysis Focus
- Review key dataset fields and their meanings.
- Identify missing or inconsistent values and potential anomalies.
- Explore possible indicators of customer delinquency risk.
- Document data quality observations and recommendations.

## Deliverables
- EDA summary report
- Dataset, subject to permission for public sharing
- Relevant presentation or supporting materials, where available
