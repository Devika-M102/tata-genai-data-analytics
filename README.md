# Tata GenAI-Powered Data Analytics Job Simulation

## Project Overview
Completed the Tata GenAI-Powered Data Analytics job simulation through Forage in September 2025. This project explores how data analytics and generative AI concepts can support customer delinquency risk assessment and responsible collections strategies in a fictional financial-services case study.

## Project Objectives
- Assess data quality and identify potential issues through Exploratory Data Analysis (EDA).
- Develop a conceptual predictive modeling approach for delinquency risk.
- Translate analytical findings into stakeholder-focused recommendations.
- Design a high-level AI-powered collections system with responsible AI safeguards.
